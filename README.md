# 火柴人打羽毛球项目仓库

组长：叶子衿

组员：吴韶峰 苑博祥 廖煜杰 翁子翔

#### 一、项目介绍

* 本游戏灵感来源于一款Flash火柴人羽毛球小游戏
* 玩家可操控画面中的火柴人角色进行羽毛球对战
* 通过键盘左右键控制火柴人 *左右移动* ，上键实现 *跳跃* ，下键用于 *挥拍击球*
* 任意一方分数率先达到7分即获胜

#### 二、软件架构

本项目采用FXGL游戏引擎的模块化架构，各模块职责清晰、低耦合高内聚，支撑游戏从启动、资源加载到核心玩法运行的全流程，具体架构如下：

1. **FXGL应用层**：提供游戏运行的GUI框架基础

  - Application主类（GameApp）：继承javafx.application.Application，负责应用启动、主舞台初始化，配置游戏窗口、标题、帧率等基础设置。
  - JavaFX场景图：使用Pane,Group等容器管理UI节点层次结构，构建游戏视觉元素层级。
  - 动画系统：基于AnimationTimer实现游戏主循环，使用Timeline和Transition处理角色移动、挥拍等补间动画。

2. **核心框架层**：提供游戏运行基础支撑，包含四大核心组件

  - 游戏对象基类（GameObject）：定义所有游戏实体（玩家角色、羽毛球、场地等）的通用属性（坐标、旋转、速度）与基础方法（位置更新、状态设置、激活控制），为上层实体类提供继承模板。
  - 场景管理系统（Room）：负责场景管理与切换，支持开始界面、游戏场景、结束界面的加载、更新与渲染，维护场景内实体的生命周期和UI节点状态。
  - 精灵动画系统（Sprite）：实现纹理资源的加载与管理，支持静态图片和帧动画的播放控制，提供动画循环、单次播放等播放模式。
  - 资源加载机制：基于FXGL资源管理器，实现图片（火柴人角色/羽毛球/场地素材）、音效（击球/得分音效）的统一加载与缓存。

3. **核心功能层**：实现游戏核心玩法逻辑，分为四大功能模块

  - 输入控制模块：通过JavaFX事件处理器监听键盘事件，处理左右键移动、上键跳跃、下键挥拍操作，并将输入状态转换为游戏内指令。
  - 物理运动模块：基于JavaFX属性绑定和变换，模拟羽毛球受重力影响的抛物线运动轨迹，计算击球时的力度传递和方向变化。
  - 比分裁判模块：使用可观察属性管理比分数据，实时检测羽毛球落点位置，判断有效得分和出界情况，在达到7分时触发游戏结束逻辑。

4. **AI对手模块**：构建电脑对手的决策逻辑，根据羽毛球位置预测落点，自动移动并选择最佳击球时机和方向，提供单人游戏体验。

  - 体验优化层：提升玩家交互体验，包含三大辅助系统
  - 动画反馈系统：为火柴人角色提供移动、跳跃、挥拍等流畅动画序列，增强操作反馈与视觉表现力。
  - 音效反馈系统：在关键操作点（击球、得分）播放对应音效，强化游戏节奏感和沉浸感。
  - 界面提示系统：在游戏过程中实时显示当前比分，在游戏结束后展示获胜方并提供重新开始选项，降低上手门槛。

5. **技术支撑层**：保障项目开发与运行，采用以下技术栈

  - 编程语言：Java 24（核心逻辑开发）
  - 游戏引擎：FXGL（实体组件系统、碰撞检测、动画管理）
  - UI框架：JavaFX 17+（界面绘制、事件处理、属性绑定）
  - 构建工具：Maven（依赖管理与项目打包）
  - 开发工具：IntelliJ IDEA（JavaFX开发支持）
  - 版本控制：Git + GitHub（代码托管与团队协作）

#### 三、模块定义
本项目按"功能边界清晰、职责单一"原则划分模块，各模块通过接口交互，具体模块及职责如下：

1. **主应用模块（main-app）**

  - 核心职责：游戏启动入口和FXGL应用初始化，配置全局游戏设置。
  - 子模块：应用配置子模块（设置窗口大小、标题、帧率等）、启动引导子模块（处理程序启动参数）。
  - 依赖模块：FXGL引擎核心模块。

2. **实体管理模块（entity-management）**

  - 核心职责：管理所有游戏实体的创建、更新和销毁，维护实体状态和属性。
  - 子模块：实体基类子模块（提供通用属性和方法）、对象控制子模块（处理实体每帧更新逻辑）。
  - 依赖模块：FXGL实体组件系统、精灵动画模块。

3. **场景控制模块（scene-control）**

  - 核心职责：管理游戏场景的切换和状态维护，处理场景内对象和UI元素的生命周期。
  - 子模块：房间管理子模块（管理多个游戏房间）、UI管理子模块（处理场景内UI节点的添加和移除）。
  - 依赖模块：实体管理模块、JavaFX场景图系统。

4. **输入处理模块（input-handler）**

  - 核心职责：监听和处理玩家键盘输入，将物理输入转换为游戏内操作指令。
  - 子模块：键盘监听子模块（注册JavaFX键盘事件）、输入状态子模块（维护当前按键状态）。
  - 依赖模块：JavaFX事件系统。

5. **精灵动画模块（sprite-animation）**

  - 核心职责：加载和管理游戏纹理资源，控制动画的播放和状态切换。
  - 子模块：纹理加载子模块（处理图片资源加载）、动画控制子模块（管理动画播放逻辑）。
  - 依赖模块：FXGL资源加载系统、JavaFX图像处理。

6. **物理运动模块（physics-movement）**

  - 核心职责：模拟游戏中的物理运动，包括羽毛球的抛物线运动和碰撞响应。
  - 子模块：运动计算子模块（计算位置和速度变化）、碰撞检测子模块（检测实体间碰撞）。
  - 依赖模块：实体管理模块、FXGL物理系统。

7. **游戏逻辑模块（game-logic）**

  - 核心职责：实现游戏核心规则和逻辑，包括比分计算、胜负判定和AI行为。
  - 子模块：比分管理子模块（跟踪和显示比分）、裁判逻辑子模块（判定得分有效性）、AI决策子模块（控制电脑对手行为）。
  - 依赖模块：实体管理模块、物理运动模块。
    
8. **UI界面模块（ui-interface）**

  - 核心职责：创建和管理游戏用户界面，提供视觉反馈和交互元素。
  - 子模块：比分显示子模块（实时显示当前比分）、菜单界面子模块（提供开始和结束界面）。
  - 依赖模块：JavaFX控件系统、场景控制模块。
